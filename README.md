# Fex Cricket 🏏

Playable browser demo of an original cricket game concept.

## Demo
Open `index.html` in a browser. It is a self-contained prototype with:
- Pakistan 🇵🇰 vs India 🇮🇳 presentation
- Bowling/ball animation
- Timing-based batting controls
- Defend / Drive / Pull / Loft
- Runs, fours, sixes and wickets
- Overs and innings state
- Mobile-friendly controls
- Keyboard controls: D / A / P / L

## Roadmap
1. Replace prototype visuals with real 3D assets.
2. Add proper bat/ball physics and shot timing.
3. Add fielding, catches, bowling variations and AI.
4. Add menus, teams, stadiums, tournaments and career mode.
5. Build Android with Unity and export signed AAB for Google Play.

This repository is an original prototype and does not use official team/player assets or branding.
